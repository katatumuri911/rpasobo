# defaults

このディレクトリは、アプリに同梱する**初期設定・カタログ**を置く。

## ルール

- ここは読み取り専用。実行時に書き込まない。
- ユーザーが変更した設定は `data/` に保存する。
- `data/` に同名ファイルがあれば、そちらを優先する。
- APIキー、サービスアカウント、VAPID秘密鍵などの秘密情報を置かない。
- 初回起動に必要で、共有してよいものだけを置く。
- 大きな会話履歴・画像・バックアップを置かない。

## 例

- `wizard_tags.json`（配布カタログ）
- `decensor.json` の初期版（将来）
- `writing_style.md` の初期版（将来）
- `char-presets.json` の初期サンプル（将来）
