📱 Android Chrome で通知を使う場合（LAN HTTP設定）

            

              Android の Chrome では、通常の HTTP 接続（LAN の IP アドレス）で通知や Service Worker がブロックされます。

              以下の手順で例外許可すると、画面消灯・スリープ中も含めて画像完成の通知が届くようになります：
            

            
    
              
  1. スマホの Chrome で下の設定URLを開きます：
                
    
                  chrome://flags/#unsafely-treat-insecure-origin-as-secure
                  
                
    
                
    ※Chromeの新しいタブを開き、アドレスバーに貼り付けて移動してください
    
              
    2. 
              
  2. 画面上部の「Insecure origins treated as secure」を Enabled に切り替えます
    3. 
              
  3. その下の入力欄に、このサーバーのアドレスを貼り付けます：
                
    
                  http://...
                  
                
    
              
    4. 
              
  4. 画面右下に出てくる青い「Relaunch」ボタンを押して Chrome を再起動します

候補の婉曲表現 → 直接表現

          
1行1組「婉曲=直接」。# でコメント。長い語から先に置換します。

            「語|手がかり1,手がかり2=直接語」と書くと、近く（前後16文字以内）に手がかりがあるときだけその訳になります。

            「穴」「そこ」「中」のような1文字・一般語は誤爆するので入れないでください（1文字の語は注意つきで保存されます）。
